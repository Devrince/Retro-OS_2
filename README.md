My Retro OS

A small retro-style operating system that runs in the browser. I built it to learn HTML, CSS, and JavaScript.

What it has
A teal desktop with My Computer, Bin, Calendar, and Calculator icons
Windows that you can drag, minimize, and close
A taskbar at the bottom that shows open windows
My Computer shows the C: drive with how much space is used
The search box in My Computer
The Bin with a file inside, which opens in a picture viewer
A calendar that highlights today
A working calculator for basic math
A clock in the bottom right corner
Files
index.html is the page and its structure
css/style.css is how it looks
js/script.js is what it does
assets/images/ has the icons and pictures
assets/cursors/ has the mouse arrow
How to run it

Open index.html in a browser. Double-click the icons on the desktop to open the apps.
