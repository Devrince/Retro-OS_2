# Retro OS

My own small operating system that runs in the browser.

I built it to learn HTML, CSS and JavaScript. It looks like an old Windows computer.

## What it has

- A teal desktop with icons
- Windows that you can drag, minimize and close
- A taskbar at the bottom
- My Computer, with a drive and a search box
- A Recycle Bin with a picture inside
- A calendar that shows today
- A calculator
- A music player for my songs
- A PDF reader for my files
- A terminal where you can type commands like `help` and `open music`
- Dino Run, a game like the Chrome dino game

## Files

- `index.html` is the page
- `css/style.css` is how it looks
- `js/` has the code for each part
- `assets/images/` has the icons and pictures
- `assets/music/` has my songs
- `assets/files/` has my PDFs

## How to run it

1. Open the folder in VS Code.
2. Open `index.html`.
3. Click **Show Preview** (Live Preview).

Note: double-clicking `index.html` may not load the music and PDFs. Use Live Preview.
